# 项目中心

v3.2 起，项目是平台中数据、训练和模型的统一入口。项目登记表保存在 `Workspace/config/projects.json`，数据集和模型本体仍保存在各自目录，不会写入 Git 仓库。

## 新建或关联项目

1. 打开“项目中心”，填写项目名称、任务类型和类别。
2. 留空数据集目录时，平台在 `Workspace/datasets/<project-id>/` 创建 `images`、`labels`、`annotations` 和 `imports`。
3. 也可以选择已有 YOLO、VOC 或分类数据集目录。
4. 激活项目后，训练页会自动填入任务、项目 ID、数据集目录和类别；标准 YOLO `data.yaml` 会直接沿用原有划分。

## 数据健康检查

项目卡片显示图片、标注和检测框数量，并检查：

- 图片没有同名标注；
- 标注没有同名图片；
- 图片损坏或无法解码；
- YOLO TXT 行格式错误、坐标越界、宽高无效；
- 数据集目录不存在或没有可训练图片。

缩略图红色边框表示当前图片缺少同名标注。检查只读取文件，不修改用户数据。

## 与模型资产联动

平台训练生成的模型通过训练清单自动关联数据集。已有 `.pt` / `.onnx` 可在“模型资产”中手动登记，填写关联数据集、任务、类别和备注。手动信息会明确标记，不会伪装成平台训练清单。
