# 半自动标注说明

半自动标注是人工标注的加速器，不是自动生成真值的替代品。它适合镜头连续、目标短时间内外观变化不大的视频或按时间排序的图片集。

## 推荐流程

1. 首帧只框选边界清晰的目标。
2. 默认选择“稳健跟踪（推荐，较慢）”。画面稳定且目标变化小时可尝试“快速跟踪”。
3. 每推进一小段就暂停抽查，不要一次播放完整段视频。
4. 红框、低质量、位置或尺寸突变出现后，选中目标并点击“修正选中框”；不需要的目标可删除。
5. 从“标注结果”随机检查已保存样本，再进入训练。

## 保存保护

网页工作台会检查每个目标：

- 跟踪器是否返回成功；
- 框中心是否发生不合理跳变；
- 面积和长宽比是否突然变化；
- Template 模式的图像匹配分数是否过低。

只要当前帧有一个目标需要复核，该帧就不会自动保存。页面会暂停播放，并增加“待复核未保存”计数。这样可以避免多目标场景中只保存部分框，悄悄制造漏标数据。

## 策略说明

| 页面名称 | 内部实现 | 建议用途 |
| --- | --- | --- |
| 稳健跟踪 | CSRT | 默认选择，遮挡较少、速度要求不高 |
| 快速跟踪 | KCF | 背景稳定、目标运动平滑 |
| 兼容模式 | Template matching | OpenCV 扩展跟踪器不可用时的回退 |
| 多视角实验模式 | CSRT + 多模板恢复 | 外观角度变化明显时试用，仍需频繁复核 |

MOSSE、MIL 等旧入口仍由兼容脚本保留，但不再放在默认网页选项中。

## 仍需改进

- 增加“回看最近 N 帧”和逐帧撤销；
- 增加未保存复核队列，而不只是计数；
- 接入检测模型辅助框选，并把模型建议与人工确认明确区分；
- 支持 YOLO TXT / COCO JSON 直接写入，减少 XML 中转；
- 建立标注一致性检查、类别分布和漏标抽样报告。
