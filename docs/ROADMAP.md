# 项目优化路线图

## P0：公开发布前必须完成

- 查明原始项目来源、许可证和需要保留的版权声明；完成 `THIRD_PARTY_NOTICES.md`。
- 选择与原始许可证兼容的本项目许可证。来源不明确前不要自行添加 MIT 等宽松许可证。
- 在全新 Windows 11、Ubuntu 22.04 和 Ubuntu 24.04 各完成一次安装、训练、ONNX 导出与重启测试。
- 确认仓库和发布压缩包不包含数据集、权重、日志、用户名、IP、密钥、虚拟环境和训练结果。
- 为公开版本建立版本号、发布说明和可复现的依赖锁定策略。

## P1：让它真正成为多平台训练工具

- 为每个设备配置建立真机验证表，而不只验证“导出成功”。
- 将 MaixCAM 专用转换完全迁移为独立适配器，移除训练主流程中的厂商路径和命名。
- 为 RKNN、D-Robotics、TensorRT 增加隔离容器或明确的外部工具链脚本。
- 在部署清单中记录预处理、归一化、颜色顺序、输出张量和 NMS 参数。
- 增加导出后自动一致性测试：同一图片比较 `.pt`、ONNX 和目标格式输出。
- 支持检测、分类之外的分割和姿态任务，并按任务限制可用部署格式。

## P1：数据与标注

- 以 YOLO TXT 为默认标注格式，VOC XML 作为兼容输入输出。
- 增加数据集版本、重复图片、坏图、漏标、越界框、类别不平衡检查。
- 半自动标注增加复核队列、撤销/重做、关键帧和插值模式。
- 后续可增加“模型辅助标注”，但任何模型建议必须经过人工确认才写入真值。

## P2：工程化与社区协作

- 拆分目前体积较大的 `train_panel.py`：API、前端资源、数据服务、训练任务、标注会话分别成模块。
- 合并网页与 `video_track_label.py` 中重复的跟踪代码，建立单一实现和单元测试。
- 增加持续集成：Python 3.10–最新版兼容检查、单元测试、安装脚本语法检查、敏感文件扫描。
- 增加英文界面/文档、贡献指南、问题模板和设备适配 PR 模板。
- 增加任务队列、断点恢复和多用户访问控制；在此之前继续默认仅监听本机地址。
